# Paikon Plus — Design

Landing page web française pour une manette fictive, esthétique cinématique noir graphite, éditoriale et technique. Scroll déterministe contrôlant une séquence produit sans autoplay. Titres Manrope, corps Poppins, chiffres monospace. Fond #08090b, surfaces #141619, texte #f3f3f0, secondaire #8d9298, accent cyan #9ae9e1. Hero asymétrique, produit dominant, navigation fine, grands titres et généreux espaces, lignes techniques, pas de cartes génériques. Quatre chapitres épinglés puis caractéristiques et CTA. Frontend uniquement, aucune table ou API supplémentaire. Séquence raster animée à partir des vues validées car génération vidéo inaccessible avec le plan courant. Fondu de jeu composé en React, aucune lecture automatique.

## Brand & Colors

CSS variables in `packages/web/src/web/product.css`. Dark-only presentation. Off-white CTA, fine charcoal borders, cyan reserved for physical product LEDs and tiny functional accents. Custom geometric mark plus lowercase paikon wordmark. No competitor marks.

## Typography

Self-hosted Manrope display 400–800 and Poppins body 400, monospace technical labels. Desktop hero 80–110px, mobile 38–47px. Generous editorial spacing and restrained labels.

## Pages & Screens

- Web `/`: product.tsx composed through index.tsx. Sticky cinematic section, technology, tactile details, FAQs, replay CTA, footer. Mobile responsive version is the same website, not a native app.

## Key User Flows

1. Scroll down to illuminate the controller, separate its components and inspect the rear; scroll up to reverse the same timeline.
2. Chapter buttons and header anchors navigate to exact timeline positions.
3. Final scroll-controlled fade reveals a fictional game menu.
4. Explore specifications and FAQ, then replay. No checkout, false price or availability claim.

## Architecture

- React/Vite on the managed Bun/Hono template; existing API plumbing retained, no new routes or tables needed.
- `use-sequence.ts`: normalized scroll selects one of181 frames, requestAnimationFrame event scheduling, no playback clock, no easing of the product timeline.
- 1120×630 desktop and720×405 mobile WebP sequences generated by scripts/render-sequence.py. Byte prefetch progressive; decoded ImageBitmap cache bounded to28 frames. Nearest decoded frame remains visible while exact frame loads.
- Public images and self-hosted fonts only in packages/web/public. Product animation uses zoom and layered raster translation plus crossfades, not a generated continuous film or true3D mesh.
